# チャットメッセージの取得
## 用語
- サンプルページ : `sample\user_chat_message_page.html`
- チャットのエレメント : `.message_balloon`
## 流れ
- サンプルページを参考にして、その要素からチャットのエレメントを取得する
- テキストと送信者を取得する
- 取得したメッセージを配列形式で返却する
## 引数
- html  : テキスト
## レスポンス
```json
[{"sender":"me/other","text":<text>},...]
```

# チャット履歴の確認
## 背景
自分、相手のどちらが最後に送信したかを記録したい。
## 要件
以下の機能を満たすコマンドを作成する
## 確認したい内容
- どちらが最後に送信したか  : 自分/相手/未送信  #数字型で表現
## DB
新規にテーブルを作成する
profilesを外部キーとして登録する
## 用語
- チャットページ : `/messages/<messageのid>`
## カラム
- id
- どちらが最後に送信したか
- profiles.id
## 流れ
- 対象ユーザーとのチャットページからチャットメッセージを取得する
  - チャットメッセージの取得機能を活用する
- どちらが最後に送信したかを判定する
- DBのテーブルに記録する
